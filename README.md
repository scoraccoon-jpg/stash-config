# Stash 配置文件

这是一个用于管理 Stash Override 配置的仓库。

主要用于保存不同使用场景下的 Stash 分流规则和策略组配置。

---

## 配置文件

### Friend Lite

文件：

`Friend-Lite-v1.0.yaml`

适用于希望简单使用 Stash 的用户。

特点：

- 简化策略组，只保留节点选择
- 国内流量自动直连
- 海外服务自动代理
- iCloud 服务直连
- Apple Intelligence / Siri 相关服务代理
- 支持 ChatGPT / OpenAI
- 支持 Telegram
- 减少手动设置，适合日常使用

适用人群：

- 不熟悉网络配置的用户
- 希望安装后直接使用的设备
